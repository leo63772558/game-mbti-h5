### 4.2 命名和接入约束

- 文件名必须使用内部 type code：`ATRB.png`、`ATRC.png`、`ATWB.png`、`ATWC.png`、`AIRB.png`、`AIRC.png`、`AIWB.png`、`AIWC.png`、`PTRB.png`、`PTRC.png`、`PTWB.png`、`PTWC.png`、`PIRB.png`、`PIRC.png`、`PIWB.png`、`PIWC.png`。
- 用户端仍不展示 type code；type code 只作为文件名和内部配置使用。
- 资源未到齐时不得提前开启 `avatarReady` 或 `imageReady`，避免 404。
- 资产替换不必递增 `contentVersion`；如果资产改变了结果理解或分享表达，需要和内容负责人确认是否递增。
