# GPTI 人物卡风格头像提示词

日期：2026-05-28

用途：替换 `assets/avatars/{TYPE}.png` 的 16 张结果头像。文件名继续使用内部 type code，但图片本身不出现 type code、英文、字母或水印。

## 统一风格

仅提取参考图的美术风格元素：

- 纯白或暖白背景，中心单人小角色，留足空白。
- 低多边形 / 几何纸片 / 扁平矢量感，边缘干净。
- Q 版短身比例，偏大头，小身体，表情简单。
- 服装和道具只保留一两个可读符号，避免复杂盔甲、场景和立绘感。
- 少量柔和脚底椭圆阴影；无背景场景、无 UI 框、无英文、无内部编码。

通用负向约束：

```text
No text, no English, no letters, no type code, no watermark, no logo, no hearts, no speech bubble, no infographic typography, no frame, no detailed armor, no realistic rendering, no dramatic lighting, no complex folds, no background scene.
```

通用基础提示词：

