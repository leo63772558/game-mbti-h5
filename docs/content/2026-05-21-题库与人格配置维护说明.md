# 题库与人格配置维护说明

> 历史说明：本文描述的是 `content-2026-05-21` 旧技术样稿结构，包含 `EI/SN/TF/JP` 维度、左右选项和旧结果字段。当前项目已正式迁移到 GPTI 新体系，题库、结果、隐藏特质和校验规则以 `2026-05-23-GPTI内容输入模板与校验规则.md` 为准。本文仅用于理解旧版本数据和历史兼容口径，不作为当前 GPTI 内容接入模板。

本文曾用于文案同学和维护者低风险更新「异界开局人格测试 / 游戏人格 H5」的旧题库与旧结果文案。

当前 GPTI 内容接入不要按本文字段执行。本文中的 `dimension`、`leftChoice`、`rightChoice`、`score_*` 只用于理解旧版本数据、旧 analytics fixture 和历史聚合兼容。

历史样稿内容版本：

```text
content-2026-05-21
```

当前 GPTI 内容版本为 `content-2026-06-10-gpti-scoring-calibration-a`，内容录入、校验和版本递增规则以 `docs/content/2026-05-23-GPTI内容输入模板与校验规则.md` 为准。当题库、结果文案、分享图或结果页承接改动会影响用户选择、结果理解或分享意愿时，需要同步递增新的 `contentVersion`。本版本在 `content-2026-06-05-gpti-side-quest-c` 基础上校准题目 `poles`，降低选项位置导致的结果偏置；16 型主结果体系、隐藏特质附加展示规则和 CloudBase 统计口径不变。

## 2. 题库字段

每道题保持以下结构：

| 字段 | 说明 | 可否直接改 |
|---|---|---|
| `id` | 题目 ID，例如 `q01`。当前测试和埋点依赖它识别题目。 | 不建议改 |
| `chapter` | 所属章节，当前为 1-4，每章 6 题。 | 中风险 |
| `dimension` | 打分维度，当前为 `EI`、`SN`、`TF`、`JP`。 | 中高风险 |
| `weight` | 题目权重，当前均为 1。 | 中风险 |
| `title` | 用户看到的题干。 | 低风险 |
| `leftChoice` | 偏负向字母一侧的选择文案。 | 低风险 |
| `rightChoice` | 偏正向字母一侧的选择文案。 | 低风险 |

低风险改题原则：

- 只改 `title`、`leftChoice`、`rightChoice`。
- 保持 24 题。
- 保持每个维度 6 题。
- 不调整 `id`、`dimension`、`weight`。

## 3. 结果字段

每个结果保持 16 个内部 type key，不向用户展示内部编码。

| 字段 | 说明 | 可否直接改 |
|---|---|---|
| `type` | 内部结果编码，必须和对象 key 一致。 | 不建议改 |
| `name` | 用户看到的结果名称。 | 低风险 |
| `identity` | 用户看到的职业身份 / 档案类型。 | 低风险 |
| `headline` | 结果页和分享文案中的核心判词。 | 低风险 |
| `worldCopy` | 异界身份说明。 | 低风险 |
| `playerCopy` | 玩家翻译说明。 | 低风险 |
| `tags` | 结果标签数组。 | 低风险 |
| `charges` | 系统罪状数组。 | 低风险 |
| `talent` | 隐藏天赋。 | 低风险 |
| `weakness` | 致命弱点。 | 低风险 |
| `bestPartners` | 适配队友数组。 | 低风险 |
| `nemesis` | 天敌队友数组。 | 低风险 |
| `shareCTA` | 分享图底部行动文案。 | 低风险 |

低风险改结果原则：

- 保持 16 个结果 key 完整。
- 保持 `type` 与 key 一致。
- 不在用户可见文案中出现 `MBTI`、`16 型人格`、`INTJ`、`ENFP` 等内部口径。
- 避免攻击现实身份、职业、地域、性别或具体群体。

## 4. 风险分级

低风险：

- 修改题干和选项文字。
- 修改结果名称、身份、判词、解释、标签、罪状、天赋、弱点、队友和分享 CTA。
- 修改章节反馈文字。

中风险：

- 调整题目顺序。
- 调整题目所属章节。
- 调整题目所属维度。
- 调整题目权重。
- 大量重写题目，导致旧版和新版数据不可直接比较。

高风险：

- 题目数量不再是 24。
- 维度不再是 `EI`、`SN`、`TF`、`JP`。
- 结果不再是 16 个 type key。
- 打分不再按四维字母组合映射结果。
- 想加入并列结果、概率结果、标签型结果或稀有度动态计算。

高风险改动必须先更新 spec 和测试，再进入实现。

## 5. 内容版本规则

需要递增 `contentVersion`：

- 改了题目或选项。
- 改了结果名称、headline 或主要解释文案。
- 改了分享文案，可能影响传播点击和分享意愿。
- 改了章节反馈，可能影响中途流失。

不需要递增 `contentVersion`：

- 只改 README、部署说明或后台看板说明。
- 只改技术实现且用户答题和结果理解不变。
- 只修错别字且不影响语义，可由维护者判断。

递增时同步修改：

- `index.html` 中的 `window.GH_ANALYTICS_CONFIG.contentVersion`
- `src/app.mjs` 中的 `CONTENT_VERSION`
- 本文档的“当前内容版本”
